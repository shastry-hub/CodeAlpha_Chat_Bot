# PyBot -- Basic Rule-Based Chatbot

PyBot is a simple Python-based rule-based chatbot that interacts with
users through text. It can answer predefined questions, tell jokes,
display the current date, provide basic career advice, and handle help
and exit commands.

## Features

-   Responds to greetings
-   Answers basic questions about PyBot
-   Tells random jokes
-   Displays the current date
-   Gives simple career advice
-   Provides a `help` command
-   Handles unknown questions with friendly responses
-   Uses random responses for variety
-   Waits 3 seconds before closing

## Technologies Used

-   Python
-   Dictionaries
-   Functions
-   `if-elif-else` statements
-   `while` loop
-   User input and output
-   `random` module
-   `time` module
-   `datetime` module

## How to Run

1.  Make sure Python is installed on your computer.
2.  Save the program as `CodeAplha_chatbot.py`.
3.  Open the file using Python IDLE or run it from Command Prompt.
4.  Start the program.
5.  Type `help` to see the supported questions.
6.  Type `bye` to end the chatbot.

## Example Commands

``` text
hello
how are you
what is your name
tell me a joke
what is the date
career advice
help
bye
```
